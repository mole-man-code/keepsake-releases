# Keepsake

Keepsake is a free companion app for **Monsters & Memories** on Windows. It reads the Ledger and NPC journal files the game already saves on your PC and turns them into session stats, loot and kill summaries, drop rates, quest and tradeskill helpers, maps, respawn timers, and in-game overlays.

**Privacy:** no account and no server, and none of your game data leaves your PC. The only thing Keepsake does online is check GitHub at start-up for a newer version. You can turn that off in **Settings → Updates**.

## Download

Get **Keepsake-portable.zip** from the [latest release](https://github.com/mole-man-code/keepsake-releases/releases/latest).

1. Unzip it anywhere.
2. Open the `Keepsake` folder and double-click `Keepsake.exe`. You don't need Python.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. That appears because the app isn't code-signed.

Keepsake finds your M&M save folder on its own. If yours is somewhere else, set it in **Settings**. The full guide is the `README.md` inside the download.
