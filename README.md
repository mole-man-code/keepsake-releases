# Keepsake

Keepsake is a free companion app for **Monsters & Memories** on Windows. It runs on your PC only: no account, no server, and nothing is sent anywhere. It reads the Ledger and NPC journal files the game already saves and turns them into session stats, loot and kill summaries, drop rates, quest and tradeskill helpers, maps, respawn timers, and in-game overlays.

## Download

Get **Keepsake-portable.zip** from the [latest release](https://github.com/mole-man-code/keepsake-releases/releases/latest).

1. Unzip it anywhere.
2. Open the `Keepsake` folder and double-click `Keepsake.exe`. You don't need Python.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. That appears because the app isn't code-signed.

Keepsake finds your M&M save folder (`%USERPROFILE%\AppData\LocalLow\Niche Worlds Cult\Monsters and Memories`) on its own. If yours is somewhere else, set it in **Settings**.

Overlays show over the game in windowed or borderless mode. Errors are logged to `%APPDATA%\Keepsake\keepsake.log`.

Please report problems on the [Issues](https://github.com/mole-man-code/keepsake-releases/issues) page.
